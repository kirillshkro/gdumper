# Каталог `internal/auth`

## Назначение

Каталог `internal/auth` отвечает за загрузку и управление cookies для авторизации на форумах. Этот модуль предоставляет функциональность для получения cookies из различных источников, необходимых для доступа к защищённым страницам форумов.

## Реализация

- **Загрузка cookies из браузеров:** Поддержка загрузки cookies из Chrome, Chromium, Brave, Edge, Firefox, Safari
- **Загрузка из файлов:** Поддержка Netscape-совместимых файлов cookies (file:/path/to/cookies.txt)
- **Загрузка из строк:** Поддержка ввода cookies в формате "k=v; k2=v2" (raw:"k=v; k2=v2")
- **Библиотека:** Использование `codeberg.org/sorl/browsercookie` для загрузки cookies из браузеров
- **Фолбэк:** Использование `github.com/aisk/browsercookies` в качестве резервного варианта для Firefox и Chrome
- **CookieJar:** Реализация http.CookieJar для использования с HTTP клиентом
- **Безопасность:** Не записывает cookies в логи
- **Форматы:** Поддержка различных форматов cookies (Netscape, HTTP Cookie Draft)
- **Проверка доступа:** Убедиться, что cookies действительны и позволяют получить доступ к теме форума

## Связанные модули

- `cmd` - использует модуль для инициализации авторизации
- `internal/fetcher` - HTTP клиент, использующий загруженные cookies
- `internal/config` - получает параметры источника cookies из конфигурации
