# Каталог `internal/config`

## Назначение

Каталог `internal/config` отвечает за парсинг и обработку конфигурации приложения, включая флаги командной строки, файлы конфигурации и переменные окружения.

## Реализация

- **Парсинг флагов:** Обработка всех флагов командной строки согласно ТЗ
- **Загрузка конфигурации:** Поддержка YAML/JSON конфигурационных файлов через `github.com/spf13/viper`
- **ENV переменные:** Поддержка переменных окружения для переопределения параметров
- **Каскадное переопределение:** Приоритет флагов > переменных окружения > конфигурационных файлов > значений по умолчанию
- **Валидация:** Проверка корректности параметров перед запуском
- **Структура конфигурации:** Хранение всех параметров в единой структуре `Config` с полями для всех флагов
- **Разбор cookies:** Обработка различных форматов источников cookies (browser:chrome|firefox|edge|safari, file:/path/to/cookies.txt, raw:"k=v; k2=v2")

## Связанные модули

- `cmd` - точка входа, которая использует эту конфигурацию
- `internal/auth` - модуль авторизации, который использует конфиг для получения параметров cookies
- `internal/fetcher` - HTTP клиент, использующий параметры из конфига (delay, retries, user-agent)
- `internal/parser` - парсер, который может использовать конфиг для специфичных правил парсинга
