# Каталог `internal/downloader`

## Назначение

Каталог `internal/downloader` отвечает за скачивание вложений с форумов. Этот модуль реализует стриминговую загрузку файлов без загрузки их в память.

## Реализация

- **Скачивание файлов:** Реализация загрузки вложений с использованием стриминга (streaming download)
- **Библиотека:** Использование `github.com/dracory/base/files` с функцией `DownloadURL(url, path)` для стриминговой загрузки
- **Альтернатива:** Собственная реализация на `io.Copy` с `net/http` при необходимости
- **Сохранение файлов:** Сохранение файлов в структуре каталогов `attachments/<post_id>/`
- **Идемпотентность:** При повторном запуске не скачивает уже сохранённые вложения
- **Хеширование:** Вычисление SHA-256 хеша файлов для проверки целостности
- **Обработка ошибок:** Обработка ошибок загрузки и проверка целостности файлов
- **Конфигурация:** Использование параметров из `internal/config` для определения стратегии загрузки (download, links, skip)
- **Ограничения:** Поддержка ограничений на частоту запросов (использует `internal/fetcher`)
- **Логирование:** Структурированное логирование операций загрузки

## Связанные модули

- `cmd` - использует для инициализации загрузки вложений
- `internal/fetcher` - использует HTTP клиент для загрузки файлов
- `internal/model` - получает информацию о вложениях для скачивания
- `internal/config` - получает параметры стратегии загрузки
- `internal/storage` - получает информацию о вложениях для сохранения
