# Каталог `internal/fetcher`

## Назначение

Каталог `internal/fetcher` реализует HTTP-клиент с устойчивостью к ошибкам и механизмами управления частотой запросов. Этот модуль отвечает за загрузку HTML-страниц форума с поддержкой повторных попыток и ограничения скорости.

## Реализация

- **HTTP клиент:** Использование `github.com/hashicorp/go-retryablehttp` для создания устойчивого HTTP клиента
- **Повторные попытки:** Поддержка экспоненциальной задержки при ошибках 5xx и 429
- **Ограничение частоты:** Использование `golang.org/x/time/rate` для управления количеством запросов в секунду
- **Заголовки:** Настройка заголовков, включая User-Agent из конфигурации
- **Cookies:** Поддержка использования cookies, загруженных модулем auth
- **Задержка:** Применение задержки между запросами из конфигурации
- **Конфигурация:** Использование параметров из `internal/config` для настройки клиента
- **Логирование:** Структурированное логирование операций загрузки
- **Безопасность:** Не записывает cookies в логи

## Связанные модули

- `cmd` - использует для инициализации HTTP клиента
- `internal/auth` - получает cookies для использования в запросах
- `internal/config` - получает параметры для настройки клиента (delay, retries, user-agent)
- `internal/parser` - получает HTML для парсинга
- `internal/downloader` - использует клиент для загрузки вложений
- `internal/paginator` - использует клиент для получения информации о страницах
