# Каталог `internal/model`

## Назначение

Каталог `internal/model` содержит структуры данных, описывающие сущности, используемые в приложении: темы, сообщения, вложения и метаданные.

## Реализация

- **Структуры данных:**
  - `Topic` - данные темы форума (ID, заголовок, URL, автор, дата создания, число страниц)
  - `Post` - данные сообщения (ID, автор, дата, тело (HTML и plaintext), ссылка на пост, номер поста, ID родителя, уровень вложенности)
  - `Attachment` - данные вложения (имя файла, URL, MIME, размер, локальный путь, SHA-256)
  - `Page` - информация о странице (HTML, URL, номер)
  - `Manifest` - метаданные обхода (время архивации, количество загруженных страниц, ошибки, завершённость)
- **Соответствие JSON схеме:** Структуры соответствуют схеме из ТЗ (см. раздел 5)
- **Маршалинг/демаршалинг:** Поддержка JSON сериализации/десериализации
- **Конвертация:** Методы для конвертации между форматами (HTML, Markdown, текст)
- **Хеширование:** Поддержка SHA-256 хеширования вложений (использует `crypto/sha256` из stdlib)

## Связанные модули

- `internal/parser` - использует для создания структур данных из HTML
- `internal/storage` - использует для записи данных в файлы
- `internal/downloader` - использует для создания структур вложений
- `cmd` - использует для работы с данными в целом
