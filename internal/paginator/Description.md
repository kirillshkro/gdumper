# Каталог `internal/paginator`

## Назначение

Каталог `internal/paginator` отвечает за определение границ страниц темы форума и генерацию URL для постраничного обхода.

## Реализация

- **Определение последней страницы:** Парсинг HTML для определения общего числа страниц темы
- **Генерация URL страниц:** Создание URL для конкретных страниц темы на основе базового URL
- **Работа с диапазонами:** Обработка различных форматов диапазонов страниц (all, 1-5, 3, 3-)
- **Пагинация:** Поддержка постраничного обхода темы от первой до последней страницы
- **Алгоритм:** Использование информации о пагинации для генерации списка URL страниц
- **Интерфейс:** Поддержка интерфейса с методами для проверки совпадения, получения последней страницы и формирования URL страниц
- **Конфигурация:** Использование параметров из `internal/config` для определения диапазона страниц
- **Ошибка обработки:** Обработка случаев, когда пагинация отсутствует или не может быть определена
- **Идемпотентность:** При повторном запуске использует уже определенную информацию о страницах

## Связанные модули

- `cmd` - использует для инициализации пагинации
- `internal/fetcher` - использует для загрузки страниц
- `internal/parser` - получает HTML страниц для определения пагинации
- `internal/config` - получает параметры диапазона страниц
- `internal/model` - использует для хранения информации о количестве страниц
