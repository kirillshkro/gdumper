# Каталог `internal/parser`

## Назначение

Каталог `internal/parser` реализует интерфейс парсинга HTML-страниц форумов. Этот модуль отвечает за извлечение данных из HTML, включая заголовок темы, сообщения, вложения и информацию о пагинации.

## Реализация

- **Интерфейс Parser:** Определение интерфейса с методами для проверки совпадения, парсинга страниц, определения последней страницы и формирования URL страниц
- **Реализация:** Реализация парсера на основе `github.com/PuerkitoBio/goquery` для jQuery-подобного API навигации по DOM
- **Поддержка движков:** Поддержка различных движков форумов через интерфейс Parser
- **Совместимость:** Использование `golang.org/x/net/html` как низкоуровневого парсера
- **Конвертация HTML в Markdown:** Использование `github.com/cybergodev/html` для извлечения текста и конвертации в Markdown
- **Извлечение данных:**
  - Заголовок темы
  - URL темы
  - ID темы
  - Автор темы
  - Дата создания
  - Число страниц
  - Сообщения (ID, автор, дата, тело, номер поста, ID родителя, уровень вложенности)
  - Вложения (имя файла, URL, MIME, размер, локальный путь, SHA-256)
- **Обработка ошибок:** Проверка корректности HTML и обработка ошибок парсинга
- **Расширяемость:** Интерфейс позволяет добавлять новые движки форумов

## Связанные модули

- `cmd` - использует для инициализации парсера
- `internal/fetcher` - получает HTML для парсинга
- `internal/config` - может использовать параметры для специфичных правил парсинга
- `internal/model` - используется для создания структур данных
- `internal/paginator` - использует для определения последней страницы
