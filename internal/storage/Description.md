# Каталог `internal/storage`

## Назначение

Каталог `internal/storage` реализует функциональность сохранения данных в различных форматах (JSON, JSONL, Markdown, HTML) в файловую систему.

## Реализация

- **Форматы вывода:** Поддержка различных форматов сохранения данных:
  - `json` - полный JSON файл с темой, сообщениями и вложениями
  - `jsonl` - JSONL (JSON Lines) формат
  - `markdown` - формат Markdown
  - `html` - формат HTML
- **Запись файлов:** Реализация записи данных в файлы по указанному пути
- **Формирование структуры:** Создание необходимой файловой структуры (pages/, attachments/)
- **Сохранение данных:**
  - `manifest.json` - метаданные обхода
  - `topic.json` - все сообщения и вложения
  - `pages/` - сырой HTML (опционально)
  - `attachments/` - вложения с сохранением структуры по ID постов
- **Идемпотентность:** При повторном запуске не перезаписывает уже сохранённые данные
- **Сериализация:** Использование стандартного `encoding/json` для JSON формата
- **Форматирование:** Поддержка форматирования данных в зависимости от выбранного формата
- **Обработка ошибок:** Логирование ошибок при записи на диск
- **Конфигурация:** Использование параметров из `internal/config` для определения формата и пути вывода

## Связанные модули

- `cmd` - использует для инициализации и вызова сохранения данных
- `internal/model` - использует для получения структур данных
- `internal/parser` - получает данные для сохранения
- `internal/config` - получает параметры формата и пути вывода
- `internal/downloader` - получает информацию о вложениях для сохранения
